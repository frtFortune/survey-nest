# SurveyNest 🎓📋

> Centralizing academic research surveys and eliminating chat group clutter for students.

## About
**SurveyNest** is a professional student survey coordination platform. It solves the chaos of scattered group chat links by matching surveys with targeted student demographics, providing branded shareable links (`surveynest.app/f/xyz`), and offering a frictionless response loop with daily digest email summaries.

## Core Features
* **Targeted Discovery**: Filter surveys by department and academic level.
* **Branded Public Links**: Shareable short links allowing respondents to fill out external forms (Google/Microsoft Forms) with **no sign-up required**.
* **Community Favorites / Trending**: Highlights popular community surveys nearing completion.
* **Smart Tracking**: Manual and visibility-triggered return flow ("Mark as Completed") to track personal contributions.
* **Daily Digest Emails**: Batched daily email notifications to avoid inbox fatigue.
* **Feedback Channel**: Direct line for users to submit suggestions and bug reports.
